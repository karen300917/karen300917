# Portafolio de Karen

Portafolio responsive inspirado en un dashboard moderno, construido con HTML, CSS, JavaScript y Bootstrap 5.

## Personalizar el contenido

Toda la información personal está centralizada en `data.js`: nombre, perfil, correo, enlaces, métricas, proyectos y habilidades. No es necesario modificar el HTML para actualizar el contenido.

## Abrir el proyecto

Puedes abrir `index.html` directamente o iniciar un servidor local:

```bash
https://karen300917.github.io/karen300917/
```
